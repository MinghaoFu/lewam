Architecture Overview

Encoder

$x_t \to z_t$

$$z_t = \text{Proj}\big(\text{ViT}(x_t)[\text{CLS}]\big)$$

ViT extracts patch tokens + CLS token; only CLS kept. Projector = MLP + BatchNorm. Dim $D$.

→

Action Encoder

$a_t \to e_t$

$$e_t = W_a \cdot a_t + b_a$$

Single linear layer. $A = \text{frameskip} \times \text{action\_dim}$

→

Forward Dynamics (FDM)

$(z_{1:T}, e_{1:T}) \to \hat{z}_{t+1}$

$$\hat{z}_{t+1:t+T} = \text{PredProj}\big(\text{ARPred}(z_{1:T}, e_{1:T})\big)$$

Causal transformer, autoregressive next-state prediction.

Action Head (Intention + Decoder)

$(z_{1:T},\; e_{<t},\; [z_\text{goal}, h]) \to \hat{a}_t$

$$\pi_t = \text{ActionPredictor}(z_{1:T},\; e_{<t} + z_\text{goal})$$ $$\pi_t' = \text{AdaLN}(\pi_t,\; h) = \text{LN}(\pi_t) \cdot (1 + \gamma(h)) + \beta(h)$$ $$\hat{a}_t = \text{ActionDecoder}(\pi_t')$$

Separate causal transformer (fresh weights). AdaLN-Zero for horizon conditioning. Decoder: MLP $D \to 2048 \to A$.

Inverse Dynamics (IDM)

$(z_\tau, z_{\tau+1}) \to \hat{a}_\tau^{\text{inv}}$

$$\hat{a}_\tau^{\text{inv}} = \text{MLP}\big([z_\tau;\; z_{\tau+1}]\big)$$

MLP: $2D \to 256 \to \text{GELU} \to A$. Train-only regularizer, never used at eval.

Loss Terms

SymbolFormulaPurpose
$\mathcal{L}_\text{pred}$$\|\hat{z}_{t+1} - z_{t+1}\|^2$FDM predicts next latent
$\mathcal{L}_\text{sigreg}$$\text{SIGReg}(z)$ — variance + decorrelationPrevents encoder collapse, structures latent geometry
$\mathcal{L}_\text{intent}$$\|\pi_t - \text{sg}(e_t)\|^2$Intention matches action embedding (stop-gradient on target)
$\mathcal{L}_\text{act}$$\|\hat{a}_t - a_t\|^2$ (MSE) or $\mathcal{L}_\text{DDPM}$Decoder recovers raw action
$\mathcal{L}_\text{inv}$$\|\hat{a}_\tau^{\text{inv}} - a_\tau\|^2$Inverse dynamics regularizer (dense: all consecutive pairs)
$\mathcal{L}_\text{sigreg\_act}$$\text{SIGReg}(e)$Prevents action-embedding collapse

Evaluation Modes

bc Behavior Cloning

Action head predicts from past observations only. No goal, no planning.

$$\hat{a}_t = \text{Decode}\big(\text{ActionPred}(z_{1:T}, e_{<t})\big)$$

Tests: can the model imitate training data?

policy Goal-Conditioned Policy

Action head receives goal image + horizon. No planning/search.

$$\hat{a}_t = \text{Decode}\big(\text{ActionPred}(z_{1:T}, e_{<t} + z_\text{goal}, h)\big)$$

Tests: can the model directly output goal-directed actions?

guided CEM + Action Head

Action head warm-starts CEM, which optimizes via world model rollouts.

$$\mu_0 = \text{ActionHead}(z_{1:T}, z_\text{goal}, h)$$ $$a^* = \text{CEM}\big(\mu_0,\; \text{FDM},\; \text{cost} = \|z_H - z_\text{goal}\|\big)$$

Tests: does the world model improve over the action head via planning?

planning Pure CEM

No action head — CEM searches from random initialization.

$$\mu_0 \sim \mathcal{N}(0, I)$$ $$a^* = \text{CEM}\big(\mu_0,\; \text{FDM},\; \text{cost} = \|z_H - z_\text{goal}\|\big)$$

Tests: how good is the world model alone for planning?

BASELINE LeWM — Original World Model (CEM Planning Only)

The original LeWM system: ViT-tiny scratch encoder ($D\!=\!192$), no SIGReg, no goal conditioning, no action head at eval. Pure CEM search over the learned world model. This is the planning-only baseline that all S10 arms are compared against.

Training Loss (world model only)
$$\mathcal{L}_\text{LeWM} = \mathcal{L}_\text{pred} = \|\hat{z}_{t+1} - z_{t+1}\|^2$$
Eval: Pure CEM over frozen world model
$$a^* = \text{CEM}\big(\mu_0 \sim \mathcal{N}(0,I),\;\; \text{FDM},\;\; \text{cost} = \|z_H - z_\text{goal}\|\big)$$

Published baseline results (N=50, seed=42): tworoom ~95%  |  cube ~67%  |  pusht ~76%  |  reacher ~85%

Epoch subscripts: 42e15 = fully trained 42e5 = undertrained (only 33% of max epochs) Results from undertrained checkpoints may improve significantly with more training.

Section C Component Ablations

Training: train.py  |  goal_conditioned=true  |  Native eval: policy  |  End-to-end (freeze_wm=false)

c_base — Baseline

ViT-tiny scratch ($D\!=\!192$), MSE action head, full history ($T\!=\!3$), SIGReg ON.

Total Loss
$$\mathcal{L} = \mathcal{L}_\text{pred} + 0.09 \cdot \mathcal{L}_\text{sigreg} + 1.0 \cdot \mathcal{L}_\text{act}$$
c_enc_dino — Pretrained Encoder

DINOv2-small pretrained ($D\!=\!384$) replaces ViT-tiny scratch. Everything else identical.

Difference from c_base
$$z_t = \text{Proj}\big(\text{DINOv2-small}(x_t)[\text{CLS}]\big) \quad \text{vs} \quad z_t = \text{Proj}\big(\text{ViT-tiny}(x_t)[\text{CLS}]\big)$$
c_head_diffusion — Diffusion Action Head

Replaces MSE decoder with DDPM denoising. Multi-modal action distribution support.

Action loss becomes diffusion loss
$$\mathcal{L}_\text{act}^{\text{DDPM}} = \mathbb{E}_{t, \epsilon}\big[\|\epsilon - \epsilon_\theta(a_t^{(k)}, k, \pi_t)\|^2\big]$$
c_input_stateonly — No Action History

Action embeddings zeroed out: $e_{<t} = \mathbf{0}$. Tests: does action history help?

$$\hat{a}_t = \text{Decode}\big(\text{ActionPred}(z_{1:T},\; \mathbf{0} + z_\text{goal},\; h)\big)$$
c_input_markov — Markov (history_size=1)

Only current state + previous action. Tests: is longer history needed?

$$\hat{a}_t = \text{Decode}\big(\text{ActionPred}(z_t,\; e_{t-1} + z_\text{goal},\; h)\big)$$
c_sigreg_off — No SIGReg (GC context)

Same as c_base but $\lambda_\text{sigreg} = 0$. Tests: SIGReg impact in goal-conditioned setting.

$$\mathcal{L} = \mathcal{L}_\text{pred} + 1.0 \cdot \mathcal{L}_\text{act}$$
c_predict_emb — + Intention Loss

Adds intention loss ($w_\text{intent}\!=\!1$) with detached decoder. Action head predicts in embedding space, then decoder maps to raw action.

Total Loss (extra term)
$$\mathcal{L} = \mathcal{L}_\text{pred} + 0.09 \cdot \mathcal{L}_\text{sigreg} + 1.0 \cdot \underbrace{\mathcal{L}_\text{intent}}_{\|\pi_t - \text{sg}(e_t)\|^2} + 1.0 \cdot \mathcal{L}_\text{act}$$

detach_decoder=true — decoder gradients don't flow back to the action predictor.

Key Findings

1. SIGReg is essential for planning, not for imitation

In bc mode, sigreg_base/act/off all score 48% on tworoom and 68% on cube — identical. But in guided mode, sigreg_off drops to 30% on pusht (vs 80% for sigreg_base). SIGReg structures the latent space so CEM can efficiently search trajectories.

2. Pretrained encoder (DINOv2) is the single biggest factor

c_enc_dino achieves 84% guided on pusht and 82% on reacher — far ahead of any other arm. The pretrained visual features provide a richer, more discriminative latent space that benefits both direct policy and CEM planning.

3. Guided > Planning > Policy (in general)

CEM planning improves over raw policy in most cases. Guided (action-head warm-start) usually beats pure planning — except for c_base and c_head_diffusion where pure CEM does better, suggesting the action head can sometimes mislead the optimizer.

4. IDM on predicted latents is catastrophic

ov_idm_dense_A8 collapses to 2% on reacher across all modes. FDM prediction error compounds through the IDM, corrupting the training signal. Always use encoded latents for inverse dynamics.

5. Diffusion head: bad for policy, good for planning

c_head_diffusion scores 2% on pusht in policy mode (denoising is too slow/noisy for one-shot prediction) but recovers to 54% in planning mode. The world model compensates for the weak action head.

6. Action history is optional

c_input_stateonly (no action history) often matches c_base. On pusht policy: 54% vs 40%. The current state + goal provides sufficient information for action selection in these tasks.

7. Markov assumption works for tworoom

c_input_markov (history_size=1) achieves 98-100% on tworoom across all modes. Navigation tasks with clear goals don't benefit from longer history. But on reacher (4% policy vs 12% c_base), the Markov constraint hurts.

8. Cube is easy, Reacher is hard

Most arms achieve 80-96% on cube in policy mode. Reacher is the discriminating task: only c_enc_dino (48% policy, 82% guided) and ov_idm_dense_on (12% policy, 50% guided) show strong performance, revealing which representations truly support fine-grained continuous control.
